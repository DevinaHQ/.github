# DevinaHQ GitHub Organization Configuration

> Organization profile, community health files, and shared GitHub configuration for DevinaHQ.

---

## Purpose

This repository is the special GitHub organization configuration repository for **DevinaHQ**.

It is intentionally limited to organization-level GitHub housekeeping such as:

- `profile/README.md` for the public organization profile
- issue templates
- pull request templates
- community health files
- shared GitHub configuration

It is **not** the canonical repository for DevinaOS architecture, governance, roadmap, product documentation, or enterprise knowledge.

---

## Canonical DevinaHQ Repository

The canonical organization-level home for DevinaHQ architecture, governance, roadmap, product map, and documentation is:

**[DevinaHQ/devina-hq](https://github.com/DevinaHQ/devina-hq)**

DevinaOS Enterprise Architecture documentation is maintained under:

**[DevinaHQ/devina-hq/docs](https://github.com/DevinaHQ/devina-hq/tree/main/docs)**

---

## Repository Boundary

```text
DevinaHQ/.github
├── profile/
├── ISSUE_TEMPLATE/        # when used
├── PULL_REQUEST_TEMPLATE  # when used
└── community health / shared GitHub config
```

Architecture and product documentation belong in `DevinaHQ/devina-hq` or their respective product repositories.
